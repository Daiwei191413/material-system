## 一、整体优化目标

V3 的核心方向是把原先偏单机使用的 BOM 工具，优化成适合团队协作的研发 BOM 整理工具。重点围绕以下几类能力展开：

1. 物料库管理：标准库和立创库云端共享、管理员维护、成员读取。
2. 原理图转立创 BOM：通过立创库把原理图 BOM 转成嘉立创下单需要的 4 列 BOM。
3. BOM 对比及转线下 BOM：以线下 BOM 参考模板为输出格式，对比并整理立创 BOM。
4. 界面命名优化：让按钮、标题、上传区域说明更贴近真实使用场景。
5. 数据稳定性：解决导入、刷新、清空、双库互相干扰等问题。

## 二、功能定位梳理

| 功能模块 | 当前定位 | 使用场景 |
| --- | --- | --- |
| 物料库管理 | 管理团队共享物料库，包含标准库和立创库两个独立库 | 管理员导入、导出、清空和维护物料库；成员读取最新库 |
| 标准库 | 公司线下 BOM 格式物料库，字段更完整 | 用于把立创 BOM 按线下 BOM 模板整理成公司内部线下格式 |
| 立创库 | 嘉立创下单格式物料库，仅保留原理图转立创需要的字段 | 用于把原理图 BOM 转成嘉立创 4 列 BOM |
| 原理图转立创 BOM | 把原理图导出的 BOM 转成嘉立创 BOM | 上传原理图 BOM，按立创库匹配 Comment、Designator、Footprint、嘉立创元件编号 |
| BOM 对比及转线下 BOM | 对比线下 BOM 参考模板和立创 BOM，并输出整理后的线下 BOM | 上传 BOM A 和 BOM B，先对比，再按线下 BOM 模板整理立创 BOM |

## 五、物料库相关优化记录

### 1. 标准库与立创库独立

已明确并按此方向优化：

- 标准库和立创库是两个独立物料库。
- 标准库用于“立创 BOM 转线下 BOM”。
- 立创库用于“原理图 BOM 转立创 BOM”。
- 两个库的导入、清空、读取、计数和展示互不干涉。
- 标准库允许部分器件存在立创编码，但不能因此把标准库当成立创库使用。

### 2. 云端共享与刷新稳定性

针对管理员导入后成员看不到、刷新后数量变少、每次刷新数量不一致的问题，已做过以下方向的修复：

- 将物料库同步从本地缓存依赖，调整为以云端团队共享库为准。
- 修复本地旧缓存把云端清空结果重新覆盖回来的问题。
- 优化大批量导入写入逻辑，减少部分数据未写入或被覆盖的情况。
- 引入更稳定的物料去重和同步键逻辑，避免刷新后数量随机减少。
- 禁用“本地缓存变化自动整库回传”，避免浏览器本地状态意外覆盖云端库。

### 3. 清空当前库

围绕“清空当前库后刷新又恢复”的问题，已做过以下调整：

- 清空动作按当前选中的库类型执行。
- 清空标准库不会影响立创库。
- 清空立创库不会影响标准库。
- 清空云端库后同步更新本地展示，避免旧数据立即回填。
- 修复云端清空接口参数必须是 `standard` 或 `lcsc` 的问题。

## 六、BOM 对比及转线下 BOM 优化记录

该模块当前业务流已经梳理为：

1. 上传 BOM A（线下BOM参考模版）。
2. 上传 BOM B（立创BOM）。
3. 选择匹配主键和对比维度。
4. 点击“开始对比”查看差异。
5. 点击“按线下BOM模板整理立创BOM”，按 BOM A 的线下格式输出整理后的 Excel。

已优化的界面说明：

- BOM A：公司线下 BOM 参考模板，决定整理后的表头和字段顺序。
- BOM B：请上传立创 BOM 文件，用于与左侧线下 BOM 参考模板做对比。
- 使用流程第 2 步：在「BOM对比及转线下BOM」页上传 BOM A（线下BOM参考模版）和 BOM B（立创BOM）。BOM A 用作线下输出格式参考，BOM B 是需要对比并整理的立创 BOM。

已删除的冗余操作：

- “按B格式整理A”已移除，因为当前真实业务需求是把立创 BOM 按线下 BOM 模板整理，而不是反向整理。

## 七、原理图转立创 BOM 优化记录

该模块当前定位已经从泛称“转嘉立创”调整为“原理图转立创BOM”。

当前功能理解：

- 输入：原理图导出的 BOM。
- 调用库：立创库。
- 输出：嘉立创 BOM 4 列格式，即 Comment、Designator、Footprint、嘉立创元件编号。
- 附加输出：映射关系附件，用于核对原始器件与立创元件编号的匹配关系。

## 十、当前状态总结

截至 V3.0.21，V3 已完成的主要非登录优化是：

- 物料库管理命名清晰化。
- 标准库和立创库业务边界明确化。
- 双库导入、清空、刷新稳定性持续修复。
- BOM 对比模块明确升级为“BOM对比及转线下BOM”。
- 上传区、流程说明和按钮名称更贴近实际操作。
- 删除了不符合当前流程的反向整理按钮。
- 原理图转立创 BOM 功能名称更准确。

后续如果继续优化，建议优先围绕以下方向：

1. 给标准库、立创库分别增加更明显的字段模板说明。
2. 在导入前增加字段识别预览，避免误把标准库导入立创库。
3. 在清空库前显示当前库类型、数量和最后更新时间，减少误操作。
4. 对“按线下BOM模板整理立创BOM”的输出结果增加预览或字段映射确认。
